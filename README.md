# MoodMirror

## MoodMirror — 나만의 감정일기

오늘의 감정을 기록하고, AI 감정 분석으로 마음 상태를 돌아보는 감정일기 웹 서비스

---

## 프로젝트 개요

**MoodMirror**는 사용자가 하루의 감정을 일기처럼 기록하면  
텍스트를 분석하여 감정, 감정 점수, 맞춤 추천 문구를 제공하는 감정 분석 웹 애플리케이션입니다.

단순히 감정을 예측하는 것에서 끝나지 않고,  
날씨나 부정 표현처럼 감정에 영향을 줄 수 있는 문맥을 함께 고려하여  
사용자에게 더 자연스럽고 따뜻한 피드백을 제공하는 것을 목표로 했습니다.

---

## 문제 정의 및 배경

일상 속 감정은 빠르게 지나가지만, 그날의 기분을 기록하고 다시 돌아보는 과정은  
자기 이해와 마음 관리에 도움이 될 수 있습니다.

하지만 감정 기록 서비스는 다음과 같은 아쉬움이 있을 수 있습니다.

- 사용자가 직접 감정을 선택해야 해서 번거로움
- 감정 결과가 단순하게만 제공됨
- 날씨, 부정 표현, 일상 문맥이 감정 분석에 충분히 반영되지 않음
- 날짜별 감정 기록을 다시 확인하기 어려움

MoodMirror는 이러한 점을 개선하기 위해  
감정일기 텍스트를 기반으로 감정을 자동 분석하고, 날짜별 기록까지 확인할 수 있도록 설계했습니다.

---

## 해결 방향

MoodMirror는 다음 방향으로 감정 기록 경험을 개선합니다.

### 1. 텍스트 기반 감정 분석

사용자가 작성한 감정일기를 머신러닝 모델로 분석하여  
대표 감정을 예측합니다.

### 2. 감정 점수 제공

예측된 감정에 따라 감정 점수를 랜덤 범위 내에서 생성하여  
사용자가 오늘의 마음 상태를 직관적으로 확인할 수 있게 했습니다.

### 3. 맞춤형 추천 문구

감정별로 준비된 긍정 문구를 랜덤으로 제공하여  
사용자가 감정을 기록한 뒤 따뜻한 피드백을 받을 수 있도록 했습니다.

### 4. 날씨 문맥 반영

입력 문장에 날씨 관련 표현이 포함되어 있으면  
날씨 때문에 기분이 영향을 받은 상황에 맞는 문구를 우선 제공합니다.

### 5. 날짜별 감정 기록

선택한 날짜별로 감정 분석 결과를 저장하고,  
기록창에서 다시 확인할 수 있도록 구현했습니다.

## 주요 기능

### 1. 감정 분석

사용자가 입력한 일기 텍스트를 분석하여 감정을 예측합니다.

분석 대상 감정:

- 기쁨
- 슬픔
- 분노
- 불안
- 우울

### 2. 키워드 기반 보정

모델이 `기쁨`으로 잘못 예측할 수 있는 부정 표현을 보정합니다.

예시:

- `기분이 좋지 않았어`
- `안 좋았어`
- `힘들어`
- `무기력해`
- `화나`

이를 통해 단순 단어 포함으로 인한 오분류를 줄였습니다.

### 3. 날씨 맞춤 문구

날씨 관련 키워드가 포함된 경우,  
감정에 따라 날씨 상황에 맞는 문구를 출력합니다.

예시:

- `오늘은 비가 와서 기분이 좋지 않았어`
- `날씨가 좋아서 기분이 좋다`
- `날씨가 너무 더워서 화난다`
- `흐린 날씨 때문에 불안하다`

### 4. 감정 점수

감정별 점수 범위를 설정하고 해당 범위 안에서 점수를 생성합니다.

| 감정 | 점수 범위 |
|---|---:|
| 기쁨 | 70 ~ 100 |
| 불안 | 35 ~ 60 |
| 슬픔 | 20 ~ 50 |
| 분노 | 10 ~ 45 |
| 우울 | 0 ~ 35 |

### 5. 날짜별 감정 기록

브라우저 `localStorage`를 사용하여  
날짜별 감정 기록을 저장하고 다시 확인할 수 있습니다.

저장되는 정보:

- 날짜
- 입력한 일기 내용
- 분석된 감정
- 감정 점수
- 추천 문구

### 6. 감성적인 UI

감정일기 주제에 맞게 부드러운 배경 이미지와  
동글동글한 폰트, 반투명 입력 카드 디자인을 적용했습니다.

## 모델 학습 방식

텍스트 분류 모델은 `train_model.py`에서 학습합니다.

### 벡터라이저

한국어 문장의 조사, 어미, 짧은 감정 표현을 잘 반영하기 위해  
문자 단위 TF-IDF를 사용했습니다.

```python
TfidfVectorizer(
    analyzer="char_wb",
    ngram_range=(2, 5),
    min_df=2,
    max_df=0.95,
    sublinear_tf=True,
)
```

### 분류 모델

```python
LinearSVC(class_weight="balanced")
```

여러 `C` 후보를 비교한 뒤,  
검증 성능이 가장 좋은 모델을 저장하도록 구성했습니다.

## API 명세

### POST `/predict`

사용자의 감정일기 텍스트를 분석합니다.

#### Request

```json
{
  "text": "오늘은 비가 와서 기분이 좋지 않았어"
}
```

#### Response

```json
{
  "input_text": "오늘은 비가 와서 기분이 좋지 않았어",
  "emotion": "슬픔",
  "score": 34,
  "positive_message": "비 오거나 흐린 날엔 슬픔이 더 선명해질 수 있어요. 오늘은 마음을 조금 더 다정하게 감싸주세요."
}
```

## 프로젝트 의의

MoodMirror는 감정 분석 모델을 활용하여  
사용자가 자신의 감정을 더 쉽게 기록하고 돌아볼 수 있도록 만든 프로젝트입니다.

특히 단순한 예측 결과만 보여주는 것이 아니라,

- 감정 점수
- 감정별 추천 문구
- 날씨 상황 맞춤 문구
- 날짜별 감정 기록

을 함께 제공하여 사용자가 자신의 하루를 더 따뜻하게 정리할 수 있도록 설계했습니다.

이 프로젝트를 통해 텍스트 분류 모델, FastAPI 서버, 웹 UI, 로컬 기록 저장 기능을  
하나의 감정일기 서비스로 통합하는 경험을 구현했습니다.
