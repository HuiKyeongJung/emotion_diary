# MoodMirror

## 🌙 MoodMirror — 나만의 감정일기

오늘의 감정을 기록하고, AI 감정 분석으로 마음 상태를 돌아보는 감정일기 웹 서비스

**나의 하루를 기록하고, 감정을 이해하고, 따뜻한 문구로 위로받는 작은 마음 거울**

---

## 📌 프로젝트 개요

**MoodMirror**는 사용자가 하루 동안 느낀 감정을 일기처럼 작성하면  
텍스트를 기반으로 감정을 분석하고, 감정 점수와 맞춤 추천 문구를 제공하는 감정 분석 웹 애플리케이션입니다.

단순히 감정을 예측하는 데서 끝나지 않고,

- 부정 표현 보정
- 날씨 문맥 반영
- 감정별 점수 제공
- 감정별 랜덤 추천 문구
- 날짜별 감정 기록 저장
- 감성적인 UI 디자인

을 함께 제공하여 사용자가 자신의 감정을 더 편하게 기록하고 다시 돌아볼 수 있도록 설계했습니다.

---

## 💡 문제 정의 및 배경

하루의 감정은 빠르게 지나가지만, 감정을 기록하고 되돌아보는 과정은  
자기 이해와 마음 관리에 큰 도움이 될 수 있습니다.

하지만 일반적인 감정 기록 방식에는 다음과 같은 아쉬움이 있습니다.

- 사용자가 직접 감정을 선택해야 해서 번거로움
- 기록은 남지만 감정 상태를 객관적으로 확인하기 어려움
- 감정 분석 결과가 단순히 라벨 하나로만 제공됨
- `좋지 않았어`, `안 좋았어`처럼 부정 표현이 모델에 잘못 해석될 수 있음
- 날씨처럼 감정에 영향을 주는 상황적 요인이 반영되지 않음
- 날짜별로 감정 기록을 다시 확인하기 어려움
- 기능은 있어도 감정일기답게 따뜻한 UI 경험이 부족함

MoodMirror는 이러한 문제를 해결하기 위해  
AI 감정 분석과 감성적인 웹 UI를 결합한 감정일기 서비스를 목표로 했습니다.

## 🎯 해결 방향

MoodMirror는 다음 방향으로 문제를 해결합니다.

### 1. 텍스트 기반 감정 자동 분석

사용자가 작성한 감정일기 문장을 머신러닝 모델로 분석하여  
대표 감정을 자동으로 예측합니다.

### 2. 감정 점수 시각화

예측된 감정에 따라 감정 점수를 제공하고,  
웹 화면에서 점수 바 형태로 보여줍니다.

### 3. 감정별 추천 문구 제공

각 감정에 맞는 긍정적이고 위로가 되는 문구를 랜덤으로 제공하여  
사용자가 감정을 기록한 뒤 따뜻한 피드백을 받을 수 있도록 했습니다.

### 4. 부정 키워드 보정

모델이 `좋다` 같은 표현에 끌려 `기쁨`으로 잘못 예측하는 상황을 줄이기 위해  
부정 표현 기반의 키워드 보정 로직을 추가했습니다.

### 5. 날씨 맞춤 문구 제공

비, 흐림, 더위, 추위 등 날씨 관련 표현이 포함된 경우  
날씨 때문에 감정이 영향을 받은 상황에 맞는 추천 문구를 출력합니다.

### 6. 날짜별 감정 기록 저장

사용자가 감정을 저장하면 브라우저 `localStorage`에 기록을 저장하고,  
날짜별 기록창에서 다시 확인할 수 있도록 구현했습니다.

## ✨ 주요 기능

### 1. 감정 분석

사용자가 작성한 감정일기를 분석하여 다음 감정 중 하나로 분류합니다.

- 기쁨
- 슬픔
- 분노
- 불안
- 우울

예시 입력:

```text
오늘은 비가 와서 기분이 좋지 않았어
```

예시 결과:

```text
오늘의 감정은 슬픔이다
감정 점수: 34점
추천 문구: 비 오거나 흐린 날엔 슬픔이 더 선명해질 수 있어요.
```

---

### 2. 감정 점수 생성

감정별로 점수 범위를 설정하고, 해당 범위 안에서 점수를 생성합니다.

| 감정 | 점수 범위 |
|---|---:|
| 기쁨 | 70 ~ 100 |
| 불안 | 35 ~ 60 |
| 슬픔 | 20 ~ 50 |
| 분노 | 10 ~ 45 |
| 우울 | 0 ~ 35 |

이 점수는 웹 화면에서 점수 바 형태로 시각화됩니다.

---

### 3. 감정별 랜덤 추천 문구

감정별로 여러 개의 추천 문구를 준비하고,  
분석 결과에 따라 랜덤으로 문구를 출력합니다.

예시:

- 기쁨: `오늘의 좋은 감정을 오래 기억해보세요.`
- 슬픔: `슬픈 날도 괜찮아요. 그런 날에도 당신은 소중해요.`
- 분노: `화가 나는 마음도 자연스러운 감정이에요.`
- 불안: `불안할 땐 지금 할 수 있는 작은 일 하나만 생각해봐요.`
- 우울: `오늘을 버틴 것만으로도 충분히 잘하고 있어요.`

---

### 4. 부정 키워드 기반 감정 보정

모델이 `기쁨`으로 예측했더라도,  
입력 문장에 부정적인 표현이 포함되어 있으면 감정을 다시 보정합니다.

보정 키워드 예시:

- `기분이 좋지`
- `기분 좋지`
- `좋지 않`
- `안 좋`
- `좋지 않았`
- `힘들`
- `무기력`
- `화나`
- `짜증`
- `불안`

예시:

```text
오늘은 비가 와서 기분이 좋지 않았어
```

단순 모델 예측에서는 `기쁨`으로 잘못 분류될 수 있지만,  
키워드 보정을 통해 `슬픔`으로 수정되도록 처리했습니다.

---

### 5. 날씨 맞춤 추천 문구

사용자가 날씨 때문에 감정이 영향을 받았다고 작성한 경우,  
감정에 맞는 일반 문구가 아니라 날씨 상황에 맞는 문구를 우선 출력합니다.

날씨 키워드 예시:

- 날씨
- 비
- 장마
- 흐려
- 흐림
- 우중충
- 습해
- 더워
- 추워
- 폭염
- 한파
- 미세먼지

지원 감정:

- 기쁨
- 슬픔
- 분노
- 불안
- 우울

예시:

```text
오늘은 날씨가 좋아서 기분이 좋다
```

```text
좋은 날씨가 기분까지 환하게 만들어준 날이네요.
```

```text
날씨가 너무 더워서 화난다
```

```text
날씨 때문에 예민해진 날엔 바로 반응하기보다 시원한 물 한 잔으로 잠시 숨을 돌려보세요.
```

---

### 6. 날짜별 감정 기록창

감정 저장하기 버튼을 누르면 선택한 날짜 기준으로 감정 기록이 저장됩니다.

저장되는 정보:

- 날짜
- 입력한 일기 내용
- 분석된 감정
- 감정 점수
- 추천 문구
- 저장 시간

기록창에서는 날짜를 선택하여  
해당 날짜에 저장된 감정 기록을 다시 확인할 수 있습니다.

저장 방식:

- 브라우저 `localStorage` 사용
- 별도 데이터베이스 없이 브라우저에 기록 저장
- 같은 브라우저에서 날짜별 기록 조회 가능

## 🧠 AI 모델 학습 방식

텍스트 분류 모델은 `train_model.py`에서 학습합니다.

### 데이터

사용 데이터:

```text
data/emotion_dataset_final.csv
```

데이터 컬럼:

- `text`
- `emotion`

사용 감정 라벨:

- joy → 기쁨
- sadness → 슬픔
- anger → 분노
- anxiety → 불안
- depression → 우울

---

### 벡터라이저 개선

한국어 문장은 띄어쓰기, 조사, 어미 변화가 많기 때문에  
단어 단위보다 문자 단위 n-gram이 감정 표현을 더 잘 잡을 수 있습니다.

따라서 다음과 같이 `char_wb` 기반 TF-IDF 벡터라이저를 사용했습니다.

```python
TfidfVectorizer(
    analyzer="char_wb",
    ngram_range=(2, 5),
    min_df=2,
    max_df=0.95,
    sublinear_tf=True,
)
```

---

### 모델 변경

초기에는 `LogisticRegression`을 사용했지만,  
성능 개선을 위해 `LinearSVC`로 변경했습니다.

```python
LinearSVC(class_weight="balanced")
```

적용한 개선:

- LogisticRegression → LinearSVC 변경
- `class_weight="balanced"` 적용
- `char_wb` n-gram 2~5 적용
- 여러 `C` 후보 비교
- 가장 좋은 성능의 모델 자동 저장

## 🌈 프로젝트 의의

MoodMirror는 단순히 감정을 분류하는 모델이 아니라,  
사용자가 자신의 감정을 기록하고 이해할 수 있도록 돕는 감정일기 서비스입니다.

이 프로젝트를 통해 다음 기능들을 하나의 서비스로 통합했습니다.

- 머신러닝 기반 감정 분석
- 한국어 감정일기 데이터 최적화
- 감정별 점수화
- 감정별 추천 문구
- 부정 표현 보정
- 날씨 문맥 반영
- 날짜별 감정 기록
- 감성적인 웹 UI
- FastAPI 기반 웹 서비스

특히 `기분이 좋지 않았어`처럼 단순 모델이 오분류할 수 있는 문장을
